# Landing page UI kit — BOTines

Marketing landing page for BOTines. **Olive + cream** brand direction
(`#7E8C54` primary, `#EDE8D0` background), DM Sans, FontAwesome 6.

Structure follows the brief: Navbar → Hero → Features → How it works → Benefits
→ Pricing → About → Final CTA → Footer. All copy bilingual-ready (default EN
for marketing, Spanish-Argentine patterns for in-product strings).

## Components

- `Nav.jsx` — sticky top nav + WhatsApp CTA
- `Hero.jsx` — headline, dual CTAs, WhatsApp chat mockup
- `WhatsAppMock.jsx` — reusable phone-frame chat widget
- `Features.jsx` — 6-card feature grid
- `HowItWorks.jsx` — 4-step timeline
- `Benefits.jsx` — impact cards with stats
- `Pricing.jsx` — 2-plan tier table
- `About.jsx` — product purpose block
- `FinalCTA.jsx` — closing WhatsApp push
- `Footer.jsx` — minimal footer

Open `index.html` to see the full marketing page.
